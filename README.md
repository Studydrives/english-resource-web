
# HUFLIT English Learning Hub

A bilingual English learning platform designed to help students improve their English skills through study materials, interactive quizzes, and learning support tools.

## Overview

HUFLIT English Learning Hub provides an accessible online learning environment where students can explore English learning resources, review academic content, practice their knowledge, and share feedback.

The platform features a clean, responsive interface designed for both desktop and mobile devices.

## Features

- **Bilingual Study Materials:** 25 learning resources presented in Vietnamese and English.
- **Search and Filtering:** Find learning materials using keywords and category filters.
- **Document Viewer:** Read learning materials directly on the website.
- **Interactive Quiz:** Complete a five-question quiz to review knowledge.
- **Learning Assistant:** Chatbot interface for learning-related questions.
- **Feedback and Survey:** Submit feedback and participate in user experience surveys.
- **Responsive Design:** Interface optimized for different screen sizes.

## Getting Started

### 1. Clone the repository

    git clone https://github.com/Studydrives/english-resource-web.git

### 2. Navigate to the project directory

    cd english-resource-web

### 3. Run the website

Open `index.html` directly in your browser or use the Live Server extension in Visual Studio Code.

**Note:** An active Internet connection is required to load external resources from CDNs.
